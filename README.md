# 🕯️ Jumenia Candles (جومنيا) - Luxury Artisanal Candles Web Store

A modern, responsive e-commerce web application with real-time 3D candle rendering, shopping bag functionality, and direct WhatsApp ticket ordering.

## ✨ Features
- **3D Real-Time Candle Showcase:** Interactive WebGL 3D model with realistic wax shaders, flame simulation, dynamic lighting, and orbit rotation controls powered by Three.js.
- **3D Product Inspection Modal:** 360-degree interactive 3D inspection for each candle in the collection.
- **Clean Minimalist Design:** High-end aesthetic with pure white studio backdrops, soft ambient shadows, luxury typography, and smooth micro-interactions.
- **Shopping Bag & Dynamic Cart:** Live subtotal calculation, free UAE shipping threshold logic, and local storage state persistence.
- **WhatsApp Ticket Checkout:** Automatic generation of structured luxury receipt tickets directed to WhatsApp (`+971 52668 0498`).
- **Fully Responsive & Mobile-First:** Mobile drawer hamburger menu, bottom quick-action triggers, and fluid grid layouts.
